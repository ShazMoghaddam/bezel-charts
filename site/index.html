Charts that look finished the moment you add them.

Ten polished chart tiles as web components. Write one HTML tag, pass your numbers, done. Every chart also exports as a static SVG for READMEs, Notion and slides, where JavaScript can't run.

Ten chart types · sample data

SparklineA trend with its latest value up front.
LineCompare series over time, with notes on key moments.
BarsTotals per period, peak highlighted.
RingsOne goal, or several nested.
DonutHow a total splits into parts.
ScatterHow two measures move together, with a trend line and its r value.
GaugeA reading on a scale, coloured by zone.
Grouped barsCompare series side by side. Separate them with a | in values.
ProgressStacked parts against a target.
HeatmapActivity by day, GitHub style. Perfect for a README.

Get the code

Add one script, then use any chart tag. Hover a chart for exact values. Every option is an attribute, so the same HTML works in plain pages, React, Vue or a CMS.

<script type="module" src="https://cdn.jsdelivr.net/gh/ShazMoghaddam/bezel-charts@1/dist/bezel-charts.min.js"></script>

<bezel-bars heading="Commits" values="4,9,6,3,8" labels="M,T,W,T,F"></bezel-bars>

Need a picture instead of a live chart? Call chart.toSVG(), or press Copy SVG above and paste the file into your README.
